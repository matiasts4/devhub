## Stem divergence from the proposal

The orchestrator's `proposal.md` "Spec deltas needed" section names stems like `pizarra-grid-environment` and `pizarra-stacking-policy`. The orchestrator-instructed stem set (this README's source) consolidates those into `board-canvas` (grid + texture + first-mount polish) and `board-element-placement` (cascade) — the new capability names. The proposal text is unchanged (do not rewrite); this README is the grep-able index.

## Non-Goals carried in the proposal (consolidated)

The following items are out of scope for Phase 1 and are intentionally not in any spec file above:

- `pizarra↔workspace` bridge (identity unification) — `pizarra-workspace-bridge` change.
- Multi-tab browser in either surface — `pizarra-browser-tabs` change.
- `transform: scale()` removal on the canvas wrapper.
- Native VTE fixes unrelated to drag.
- Default browser URL alignment between `shapeModel.js` and `PizarraBrowserSurface`.
- Dead placeholder cleanup of `src/components/workspace/PizarraPane.jsx` and `usePizarraState.js`.
