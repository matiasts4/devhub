## Critical path

The critical path is the chain of tasks where any delay blocks the rest:

```
T-001 (migration) → T-002 (binary) → T-003 (wrapper helpers) → T-006 (shim) → T-005 (CLI) → T-010 (E2E)
```

If T-001 slips → everything slips (binary has no tables to write to).
If T-002 slips → wrapper helpers have no backend to call.
If T-003 slips → T-006 shim has nothing to delegate to; T-010 E2E cannot run.
If T-006 slips → `_devhub_tell_director` callers are not bridged; **launch-e743667a failure pattern cannot be fixed**.

**T-001, T-002, T-003, T-006 are the critical path.** T-004 (lock) and T-009 (snapshot) are parallelizable; T-005, T-007, T-008, T-010 are tail tasks.
